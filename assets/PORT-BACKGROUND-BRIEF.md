# 항구 배경 16장 제작 의뢰서

**tradeship — 지중해 교역기** / 2D 픽셀아트 항구 배경 / 400×225 WebP × 16장

이 문서 하나만 읽고 작업할 수 있게 썼습니다. 게임 코드를 볼 필요는 없습니다.

---

## 0. 한 줄 요약

> 15~16세기 지중해의 항구 도시 16곳을, **각 도시가 서로 구별되도록** 400×225 픽셀아트 배경으로 그려 주세요.

지금 게임에는 이미 배경이 있습니다. 문제는 **16곳이 다 똑같아 보인다**는 것입니다.
이 의뢰의 목적은 "더 예쁜 그림"이 아니라 **"베네치아에 도착했을 때 베네치아인 줄 아는 것"** 입니다.

---

## 1. 왜 다시 그리는가 — 지금 무엇이 잘못됐나

현재 배경은 코드로 생성되며, 도시마다 다른 것은 **건물 폭·높이·창문 불빛 위치**뿐입니다.
정체성을 만드는 요소가 전부 고정되어 있습니다:

| 요소 | 현재 상태 |
|---|---|
| 랜드마크 | 항상 **2개**, 항상 **x=300과 x=54**, 양식별로 **모양 1종** |
| 해안 성벽 | 모든 도시에 **화면 가로 전체**를 가로지르는 성벽 |
| 수문(아치) | 모든 도시 **x=186** 고정 |
| 방파제 기둥 | 모든 도시 **x=96, x=288** 고정 |
| 뒷산 | 모든 도시에 **같은 2겹 구릉** (평지 도시에도 산이 있음) |
| 부두 화물 | 모든 도시 같은 자리에 같은 상자·통 |
| 바다 색 | 전 도시 동일 |

그 결과 **베네치아·제노바·마르세유·바르셀로나·나폴리·팔레르모가 사실상 같은 그림**입니다.
알렉산드리아(나일 삼각주 평지)에 산이 있고, 베네치아(석호)에 산이 있습니다.

**그래서 이번 의뢰의 핵심 요구는 "도시마다 실루엣이 달라야 한다"입니다.**
색만 바꾸거나 건물 배치만 흔든 결과물은 지금 문제를 그대로 반복합니다.

## 2. 필수 규격 (어기면 게임에 못 넣습니다)

| 항목 | 값 |
|---|---|
| 해상도 | **정확히 400 × 225 px** (게임 논리 해상도 그대로) |
| 포맷 | **WebP** (무손실 `lossless` 권장, 아니면 `quality 90+`) |
| 알파 | **불투명** — 배경이므로 투명 영역이 없어야 합니다 |
| 안티에일리어싱 | **금지** |
| 스케일링 | **금지** — 200×112를 2배 확대하지 마세요 |
| 파일 크기 | 장당 **60KB 이하** 목표 (16장 합계 1MB 미만) |

### 안티에일리어싱 금지가 중요한 이유

게임은 이 그림을 **정수배로 확대**해서 화면에 띄웁니다(400×225 → 1600×900 등).
확대할 때 보간을 끕니다(`imageSmoothingEnabled = false`).
흐린 가장자리가 있으면 그 흐릿함이 **4배로 같이 커져** 뭉갠 그림처럼 보입니다.

- 반투명 픽셀·그라데이션 블러·소프트 브러시를 쓰지 마세요.
- 하늘 그라데이션은 **띠(band) 단위**로 계단지게 끊으세요. 부드러운 그라데이션이 아니라, 색 띠 5~8개입니다.
- 크기가 다르면 게임 콘솔에 경고가 뜹니다:
  `[assets] 'scene:port:latin:1101' 규격이 다르다 — 코드 기준 400×225, 넣은 그림 ...`

### ⚠️ 생성형 AI로 만들 때 반드시 거쳐야 하는 후처리

이미지 생성 모델은 **진짜 픽셀 그리드를 만들지 못합니다.** "픽셀아트 스타일"을 요청해도
실제로는 고해상도 이미지에 픽셀처럼 보이는 무늬를 그린 것이라, 확대하면 정체가 드러납니다.
반드시 아래를 거쳐 주세요.

1. 크게 생성 (예: 1600×900)
2. **최근접 이웃(nearest neighbor)** 으로 400×225로 축소 — 절대 bilinear/bicubic 쓰지 마세요
3. **색 수를 64색 이하로 양자화**(quantize), 디더링 끄기
4. 400×225에서 **1픽셀 단위로 손보정** — 특히 수평선·부두선·건물 윤곽
5. WebP로 저장

3번을 건너뛰면 "픽셀아트처럼 보이는 흐릿한 그림"이 되고, 게임의 나머지 요소(코드로 그린
배·사람·아이콘)와 톤이 어긋나 **그림만 겉돕니다.**

## 3. 화면 구조 — 어디에 무엇이 오는가 (가장 중요)

**세로 배치는 16장 전부 동일해야 합니다.** 이 선들이 어긋나면 배가 공중에 뜨거나 물에 잠깁니다.

```
y=0    ┌─────────────────────────────────────────┐
       │  하늘 · 구름 · 새                        │
y=64   │ ······ (여기부터 배의 돛대가 겹침) ······ │
       │  원경: 산 / 사구 / 평지 / 섬             │
       │                                         │
       │  중경: 시가지 스카이라인 · 랜드마크      │
y=134  │  해안 구조물 (성벽·방파제·부두 창고)     │
y=150  ├───────── 수평선 (HORIZON) ──────────────┤
       │  정박 수면                              │
y=168  │ ······ 배의 흘수선이 정확히 여기 ······· │
       │                                         │
y=186  ├───────── 부두 상판 (QUAY_Y) ────────────┤
       │  석재 부두 — 사람이 서는 바닥            │
y=225  └─────────────────────────────────────────┘
```

| 선 | y좌표 | 의미 | 지켜야 하는가 |
|---|---|---|---|
| 수평선 | **150** | 육지/해안구조물이 끝나고 물이 시작 | **절대 고정** |
| 배 흘수선 | **168** | 여기에 배가 뜹니다 | **절대 고정** (물이어야 함) |
| 부두 상단 | **186** | 여기부터 아래는 딛는 바닥 | **절대 고정** |

y=150~186은 **반드시 물**이어야 하고, y=186~225는 **반드시 평평한 부두 바닥**이어야 합니다.
이 두 구간에 건물이나 바위를 넣지 마세요 — 배가 건물에 박히고 사람이 바위 위에 뜹니다.

### 그림 위에 게임이 겹쳐 그리는 것들

배경만 보면 완성돼 보여도, 실제 화면에서는 아래가 **위에 덧그려집니다.**

| 겹치는 것 | 위치 (x, y) | 주의 |
|---|---|---|
| **플레이어 배** | x **132~308**, y **64~192** | 화면 한가운데 큰 배가 뜹니다. **이 영역에 중요한 것을 두지 마세요** |
| 부두 인부 3명 | x 8~150, y 150~195 | 왼쪽 부두에 사람이 섭니다 |
| 부관(에이미) | x 108, y 150~195 | 배 왼쪽에 섭니다 |
| 조선소 대포 | 부두 위 | 같은 배경을 조선소 화면에서도 씁니다 |

**따라서 도시의 정체성은 `y < 64`(하늘·먼 산)와 `y 64~150` 중 배에 가려지지 않는 좌우 구간에서 읽혀야 합니다.**
특히 **랜드마크는 x 0~130 또는 x 310~400에 두는 것이 안전**합니다. 가운데는 배가 가립니다.

### UI 패널에 가려지는 구간

화면 좌우에 반투명 UI 패널이 뜹니다. 창 크기에 따라 달라지지만 대략:

- 왼쪽 **x 0~130** — 시장 패널이 덮음
- 오른쪽 **x 305~400** — 정비/부관 패널이 덮음
- 가운데 **x 130~305** — 항상 보이는 구간

> 랜드마크 배치가 딜레마입니다. 가운데는 **배**가 가리고, 좌우는 **UI**가 가립니다.
> **해결책: 랜드마크를 높게 세우세요.** y < 64 구간(하늘)은 배도 UI도 거의 안 가립니다.
> 종탑·미나레트·등대처럼 **하늘을 찌르는 수직 실루엣**이 이 게임에서 가장 잘 읽힙니다.
> 이것이 도시 구별의 1순위 수단입니다.

## 4. 색 — 게임 팔레트에 맞추기

게임의 나머지 그림(배·사람·아이콘)은 아래 팔레트로 그려져 있습니다.
**여기서 벗어난 채도 높은 색을 쓰면 배경만 튀어 보입니다.**

```
아웃라인   #17121c (순검정 대신 보라기 섞인 먹색)
돌        #443f3c / #6f6961 / #a49b8a
나무      #3d2a1b / #6b4626 / #9c6b38 / #c99a5c
바다      #0e2a40 / #1b5570 / #3f93ab / #8fd3d8
하늘      #2b4a72 / #6f93bb / #c2d5e4
모래·황토  #8a6a44 / #c2a06a / #e6cd9a
초록      #26432a / #456f39 / #79a44f
금        #8a641a / #d2a52a / #f4dd86
붉은색     #711d29 / #b8323a / #e06053
천        #a89a84 / #ded2b8 / #f7f0dd
```

**규칙: 색군마다 그림자/기본/하이라이트 3톤을 정해 두고 그 안에서만 고르세요.**
"싸구려 픽셀아트"로 보이는 가장 큰 원인 두 가지가 **단색으로 채운 넓은 면**과 **팔레트 난잡**입니다.
넓은 면(하늘·바다·성벽)은 반드시 3톤 이상으로 나누세요.

**도시별로 팔레트를 살짝 틀어도 됩니다** — 오히려 권장합니다.
알렉산드리아는 더 노랗고 뿌옇게, 이스탄불은 더 푸르게, 알제는 더 하얗게.
단 위 표에서 **±1톤 범위** 안에서만 움직이세요.

## 5. 도시 16곳 — 개별 지시

각 도시의 **① 랜드마크(하늘에 찌를 수직 실루엣)**, **② 지형**, **③ 수변 성격**, **④ 색조**를 지정합니다.
④는 참고이고, **①②③이 서로 달라야 한다는 것이 이 의뢰의 핵심**입니다.

### 라틴권 (이탈리아·프로방스·카탈루냐) — 테라코타 지붕, 종탑

**1. 베네치아 `venezia`** — 시작 도시. 가장 공들여 주세요.
- ① **캄파닐레(종탑) 한 채가 압도적으로 높게** + 그 옆 돔. 첨탑이 하늘 절반을 차지해도 좋습니다
- ② **산 없음.** 석호(潟湖) — 수평선까지 평평합니다. 이것만으로도 다른 라틴 도시와 구별됩니다
- ③ 물이 **건물 벽까지 차 있음**. 부두가 아니라 운하 입구 느낌. 나무 말뚝(브리콜레)이 물에 박혀 있음
- ④ 물빛이 탁한 초록기(석호), 벽은 바랜 분홍·테라코타

**2. 제노바 `genova`** — 베네치아의 라이벌. 정반대로 그려 주세요.
- ① 등대(라 란테르나) — **가늘고 아주 높은 흰 탑**
- ② **산이 바다까지 바짝 내려옴.** 도시가 급경사에 층층이 매달림 — 건물이 계단처럼 겹쳐 올라감
- ③ 좁고 깊은 만, 돌 방파제가 길게 감쌈
- ④ 회색 돌 + 짙은 초록 산

**3. 마르세유 `marseille`** — 프랑스.
- ① 언덕 위 **작은 요새 하나**(노트르담 언덕). 도시보다 높은 바위 언덕이 특징
- ② 좌우로 **하얀 석회암 절벽**이 만을 감쌈
- ③ 폭이 좁고 안쪽으로 깊은 만
- ④ 밝은 석회암 흰색·베이지, 남프랑스의 마른 빛

**4. 바르셀로나 `barcelona`** — 스페인.
- ① **고딕 성당의 각진 첨탑 여러 개** (돔 아님, 뾰족한 것 여러 개)
- ② 뒤에 **낮고 평평한 능선** 하나. 산이 멀고 낮음
- ③ 길게 뻗은 **직선 해안 + 넓은 부두**. 만이 아니라 열린 해안
- ④ 붉은 벽돌 + 따뜻한 모래색

**5. 나폴리 `napoli`** — 스페인령.
- ① **바다에 면한 육중한 성**(카스텔 델로보 — 물 위에 솟은 돌덩어리)
- ② 뒤에 **원뿔형 화산 실루엣**(베수비오) — 이 도시의 결정적 단서입니다. 정상에서 옅은 연기
- ③ 넓게 열린 만
- ④ 따뜻한 황토, 하늘에 옅은 화산재 기운

**6. 팔레르모 `palermo`** — 시칠리아.
- ① **아랍-노르만 양식의 붉은 돔 여러 개** — 라틴권인데 돔이 있는 유일한 도시
- ② 뒤에 **깎아지른 바위산**이 도시를 병풍처럼 두름
- ③ 야자수가 보이는 부두
- ④ 라틴권 중 가장 남국적 — 붉은 돔 + 마른 황토

### 헬레닉권 (그리스·에게·아나톨리아) — 백벽, 청색 돔

**7. 아테네 `athens`** — 오스만령.
- ① 언덕 위 **폐허가 된 신전의 기둥 열**(파르테논). 지붕이 없고 기둥만 남은 실루엣
- ② 도시 뒤 **바위 언덕(아크로폴리스)이 우뚝**
- ③ 작고 소박한 어항 — 큰 항구가 아닙니다
- ④ 대리석 흰색 + 마른 올리브 초록

**8. 로도스 `rodos`** — 성 요한 기사단령. **오래된 군사 요새 도시**입니다.
- ① 탑이 아니라 **거대한 성벽과 각루(角樓)** 자체가 랜드마크. 항구 입구 양쪽에 방어탑
- ② 산은 낮게
- ③ **항구 입구가 쇠사슬로 막힌 좁은 군항**. 성벽이 물까지 내려옴
- ④ 회갈색 석재 일색. 기사단 십자기(흰 바탕 붉은 십자)를 성벽에 걸어 주세요

> 몰타(16번)도 같은 기사단령이라 **둘이 헷갈리지 않게 갈라 주세요.**
> 로도스는 **수백 년 묵은 완성된 요새** — 성벽이 높고 두껍고 이끼가 끼어 있습니다.
> 몰타는 **막 쌓기 시작한 신흥 기지** — 낮고 공사 중입니다. 같은 깃발, 다른 나이.

**9. 이스탄불 `istanbul`** — 오스만 수도. **가장 화려해야 합니다.**
- ① **거대한 중앙 돔 + 그 주위를 둘러싼 가늘고 높은 미나레트 4~6개**. 지중해에서 가장 압도적인 스카이라인
- ② 물이 **양쪽으로 갈라지는 해협** — 반대편 기슭이 보입니다(이 도시만의 특징)
- ③ 배가 빽빽한 대항구, 언덕에 궁전
- ④ 청회색 납지붕 + 금빛 첨탑 끝

**10. 부르사 `bursa`** — 오스만 내륙. **실제로는 항구가 아닙니다**(생사 1차시장, 게임 편의상 항구 처리).
- ① 낮은 돔 여러 개 + 미나레트 2개. 소박하게
- ② **뒤에 눈 덮인 큰 산**(울루다) — 지중해에서 유일하게 **만년설**이 보이는 배경
- ③ 물가는 작게, 내륙 도시 느낌. 뽕나무밭이 보이면 좋습니다(생사 산지)
- ④ 초록 + 흰 산정. 다른 어느 도시보다 서늘한 색

**11. 이즈니크 `iznik`** — 오스만 내륙. **도자기 산지**, 아주 작은 마을.
- ① 랜드마크 없음에 가깝게. 낮은 성벽과 작은 돔 하나
- ② **호수**입니다(바다 아님) — 잔잔하고 건너편 기슭이 보임
- ③ 물가에 **도자기 가마의 연기**가 몇 줄기. 이것이 이 마을의 유일한 단서
- ④ 이즈니크 도자기 색 — 흰 바탕에 코발트 블루 악센트

### 레반트권 (마그레브·레반트) — 황토벽, 미나레트

**12. 튀니스 `tunis`** — 하프스 왕조. 해적 나포선 개조항.
- ① 미나레트 + **낮고 넓게 퍼진 백색 메디나**(구시가)
- ② 뒤에 **소금호수와 평평한 지평선**
- ③ 부두에 **나포해 온 배들이 개조 중** — 돛이 없거나 뼈대만 남은 선체
- ④ 눈부신 흰색 + 짙은 파랑 문짝. 마그레브 특유의 흰-파랑 대비

**13. 알제 `algiers`** — 오스만령. 코르세어의 수도.
- ① **가파른 언덕에 흰 집이 계단처럼 빽빽이** 쌓인 카스바. 개별 랜드마크보다 이 질감 자체
- ② 언덕이 바다까지 급하게 떨어짐
- ③ **요새화된 군항** — 대포가 늘어선 방파제
- ④ 강렬한 백색 + 그림자의 짙은 파랑

**14. 베이루트 `beirut`** — 오스만령 레반트.
- ① 미나레트 + 낮은 성채
- ② **뒤에 높은 설산 산맥**(레바논 산맥)이 바다 바로 뒤에 벽처럼. 부르사와 달리 **산맥이 길게** 이어짐
- ③ 삼나무가 보이는 소박한 항구
- ④ 황토 + 뒤쪽 산의 보라빛 그림자

**15. 알렉산드리아 `alexandria`** — 오스만령 이집트. **곡물 항구.**
- ① **거대한 등대**(파로스의 후신 요새) — 이 도시의 결정적 단서
- ② **완전한 평지.** 산이 하나도 없어야 합니다 — 나일 삼각주
- ③ 곡물 창고가 늘어선 넓고 낮은 부두, 곡물 자루 더미
- ④ 사막 먼지 낀 누런 하늘, 뿌연 대기. 16곳 중 가장 건조하고 노란 그림

### 기사단령

**16. 몰타 `malta`** — 성 요한 기사단령(1530~). 시칠리아 해협 한복판의 바위섬.
- ① **십자가를 인 요새 성채**. 로도스를 잃고 새로 쌓는 중이라 **완성된 대도시가 아닙니다** —
  성벽이 낮고 공사 중인 부분이 보이면 좋습니다. 기사단 십자기(흰 바탕 붉은 십자)를 여기에 겁니다
- ② **나무가 거의 없는 맨 바위섬.** 초록을 최소로 — 16곳 중 가장 헐벗은 그림입니다.
  산이 아니라 낮고 평평한 석회암 대지
- ③ **깊고 좁은 천연 항만**이 손가락처럼 육지로 파고듭니다. 부두에 **나포해 온 배들**이
  돛대가 부러진 채 매여 있고, 경매를 기다리는 화물 더미가 쌓여 있습니다
- ④ 꿀빛 석회암(#c2a06a 계열) + 짙푸른 물. 흙먼지가 아니라 **돌먼지**의 건조함

> 로도스(8번)와 같은 기사단 깃발이지만 **나이가 다릅니다** — 로도스는 오래된 요새,
> 여기는 막 쌓는 중입니다.
>
> 이 섬의 성격은 "생산하지 않고 빼앗아 파는 곳"입니다. 밭도 숲도 없고, 요새와 부두와
> 나포선만 있습니다. 알제(빽빽한 흰 집)와 헷갈리지 않게 — 알제는 도시가 빽빽하고,
> 몰타는 **비어 있고 요새만 큽니다.**

## 7. 검수 기준 (이걸로 합격/불합격을 가릅니다)

납품물은 아래를 순서대로 확인합니다.

1. **400×225인가.** 아니면 즉시 반려
2. **400×225에서 100% 배율로 봤을 때** 픽셀이 또렷한가. 흐린 가장자리가 있으면 반려
3. **y=150 / 168 / 186 선이 지켜졌는가.** 게임에 넣고 배가 물에 뜨는지 확인
4. **16장을 나란히 놓았을 때 어느 것이 어느 도시인지 구별되는가** — 이것이 이번 의뢰의 존재 이유
5. **하나씩 봤을 때 게임의 다른 그림(배·사람)과 톤이 맞는가**

특히 4번을 위해, **작업 중에도 16장을 한 화면에 늘어놓고 비교**해 주세요.
하나씩 보면 다 그럴듯한데 모아 놓으면 똑같은 것이 지금 문제입니다.
