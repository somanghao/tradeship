# 에셋 팩 — 그림을 PNG로 갈아 끼우기

이 게임의 그림은 전부 코드로 그린다(`js/sprites/*.js`). 하지만 **코드를 몰라도 그림을 바꿀 수 있다.**
모든 스프라이트는 `bake(key, …)`라는 한 곳을 지나가고, 그 `key`로 PNG를 등록하면 코드 대신 그 그림이 쓰인다.

## 1. 키를 찾는다

```bash
python serve.py
```

<http://localhost:8891/preview.html> 을 연다. 그림마다 아래에 회색 키가 적혀 있다.

```
카라벨
ship:caravel:oak:venice:...      ← 이게 키다
```

상단의 **[키 전체 복사]** 버튼을 누르면 지금 존재하는 모든 키가 manifest 뼈대 모양으로 클립보드에 담긴다.

## 2. manifest.json을 만든다

이 폴더(`assets/`)에 `manifest.json`을 둔다.

```json
{
  "name": "손그림 팩",
  "sprites": {
    "icon:spice": "icons/spice.png",
    "scene:map": "map/mediterranean.png"
  }
}
```

경로는 이 폴더 기준 상대경로다. 위 예시라면 `assets/icons/spice.png`에 파일을 두면 된다.
**바꾸고 싶은 것만 적으면 된다** — 적지 않은 스프라이트는 코드 생성 그대로 남는다.

## 3. 규격을 맞춘다

| 종류 | 크기 | 비고 |
|---|---|---|
| 병종 | 48×48 | 발밑이 아래쪽에 닿아야 한다 |
| 선박 측면 | 176×128 | **수면선 y=104** — 이 선에 흘수가 맞아야 물에 뜬 것처럼 보인다 |
| 선박 탑다운 | 28×28 | 뱃머리가 위(북쪽) |
| 교역품 아이콘 | 16×16 | |
| 배경(지도·항구·외해) | 400×225 | 게임 논리 해상도 그대로 |

크기가 다르면 게임이 콘솔에 경고를 띄운다. 그려도 동작은 하지만 기준점이 어긋나
배가 물에 잠기거나 사람이 공중에 뜬다.

- **투명 배경(알파) 필수.** 흰 배경 PNG를 넣으면 흰 사각형이 그대로 보인다.
- **안티에일리어싱 없이** 그린다. 게임이 정수배로 확대하기 때문에 흐린 가장자리가 그대로 커진다.
- 색은 `js/pixel.js`의 `PAL` 표를 참고하면 나머지 화면과 톤이 맞는다.

## 4. 확인한다

새로고침하면 바로 반영된다. 콘솔에 이렇게 뜨면 성공이다.

```
[assets] '손그림 팩' — 스프라이트 3/3개를 갈아 끼웠다.
```

`manifest.json`이 없으면 아무 일도 일어나지 않는다 — 그게 기본 상태다.
파일 하나를 못 읽어도 그 스프라이트만 코드 생성으로 남고 나머지는 정상 동작한다.

## 왜 이렇게 했나

그림 담당과 코드 담당이 같은 파일을 건드리지 않기 위해서다.
`js/sprites/`를 고치면 충돌이 나지만, `assets/` 아래는 온전히 그림 담당의 몫이다.
