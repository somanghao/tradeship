## 세션필독

`claude-memory.md`(라우터) + `wiki/gotchas.md`(도메인 무관 함정)는 **매 세션 읽는다.** 도메인 전용 함정은 각 도메인 파일 **§3**이라 그 작업이면 반드시 도달한다.

## 가드 (도메인 무관 · 고빈도)

- 그리기 코드를 고쳤는데 화면이 그대로면 **`bake` 캐시** — 새로고침한다.
- 실행은 반드시 **`python serve.py`** — `file://`은 CORS, `-m http.server`는 낡은 캐시로 화면이 검게 뜬다(gotchas #5·#6). 웹 출력은 Artifact 금지, 로컬 서버로.
- 코드로 그린 그림은 **렌더해서 눈으로 확인**하기 전까지 품질을 단정하지 않는다.
- 검증 스크립트는 **exit code가 아니라 마지막 요약 줄**(`규칙 — N/N 통과`)로 판정한다.
