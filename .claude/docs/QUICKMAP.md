# QUICKMAP — 도메인 인덱스

> 작업 도메인을 고르고 해당 `QUICKMAP-<도메인>.md`를 Read한다. 도메인 파일은 `§1~2 키워드→문서` + `§3 그 도메인 전용 함정`이라 자족적이다.

| 도메인 | 관장 | 언제 이리로 |
|---|---|---|
| **[art](QUICKMAP-art.md)** | 픽셀 에셋 · 지도 지형 · 항구 배경 | 캐릭터·선박·아이콘·이펙트를 만들거나 고칠 때, 지형/배경이 이상할 때, 새 병종·선종·도시 양식을 넣을 때 |
| **[game](QUICKMAP-game.md)** | 교역 경제 · 해상 전투 | 시세·단가·밸런스를 조정할 때, 도시/교역품/적/병종을 추가할 때, 전투 규칙을 바꿀 때 |
| **[engine](QUICKMAP-engine.md)** | 캔버스/DOM 구조 · 씬 매니저 · UI 레이아웃 · 실행/디버깅 | 씬을 추가·전환할 때, 레이아웃·입력·좌표가 어긋날 때, 게임을 띄워 확인할 때 |

## 세션필독

`claude-memory.md`(라우터)와 `wiki/gotchas.md`(도메인 무관 함정)는 **매 세션 읽는다.**
도메인 전용 함정은 각 도메인 파일 **§3**에 있으니 그 도메인 작업이면 여기서 반드시 도달한다.

## 가드 (도메인 무관 · 고빈도)

- 그리기 코드를 고쳤는데 화면이 그대로면 **`bake` 캐시** — 새로고침한다.
- 실행은 반드시 **`python serve.py`** (ES 모듈이라 `file://`은 CORS로 막히고, `-m http.server`는 낡은 모듈 캐시로 화면이 검게 뜬다). 웹 출력은 Artifact 금지, 로컬 서버로.
- 코드로 그린 그림은 **렌더해서 눈으로 확인**하기 전까지 품질을 단정하지 않는다.
