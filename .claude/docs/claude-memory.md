# tradeship — 지중해 교역기

대항해시대 2 풍의 지중해 무역·전투 캐주얼 게임. 웹(순수 ES 모듈 + Canvas, 빌드 없음), 픽셀아트.

## ★ 세션시작 필독 (BLOCKING)

1. **이 파일** + **`wiki/gotchas.md`**(도메인 무관 함정) 를 반드시 먼저 읽는다.
2. **작업 대상이 정해지면 `QUICKMAP.md`를 Read**해 도메인을 고르고, 해당 `QUICKMAP-<도메인>.md`로 간다.
   도메인 파일은 `§1~2 키워드→문서` + `§3 그 도메인 전용 함정`이라 자족적이다.
3. **"마지막 작업이 뭐였나"를 물으면 `git log` + `changelog.md` 맨 위**를 본다 — 이 파일은 *최종상태*만 담고 경위는 담지 않는다.

도메인: **art**(픽셀 에셋·지형·배경) / **trade**(경제·물가·NPC·고증) / **combat**(전투·선박·조선소) / **engine**(캔버스·씬·UI·실행)

## 절대 원칙

- **★ 콘텐츠는 풍부하게, 금액은 근거에 충실하게 — 이 둘을 섞지 않는다(최상위 지침).**
  - **콘텐츠**(배·교역품·도시·해적·사건의 *종류*)는 **많을수록 좋다. 어떤 장치도 이것을 제약해선 안 된다.**
    근거가 아직 없다는 이유로 도시·품목·선종을 못 넣으면 안 된다 — **먼저 넣고 근거는 뒤따른다.**
  - **금액·시세**(값·비율·위험도)는 사료에 충실하고 현실적이어야 한다. **돈은 어렵게 벌려야 재미가 있다** —
    수익을 올려 달라는 압력이 오면 근거부터 확인하고, 근거가 아니라 편의면 올리지 않는다.
  - ⚠️ **검증 스크립트가 콘텐츠를 억제하는 장치가 되기 쉽다.** 그래서 실패/경고를 갈라 둔다:
    **실패**(exit 1)는 *코드와 근거가 어긋남·규칙이 자기모순*일 때만. **경고**는 밴드 이탈·미조사.
    "근거 없음"으로 실패시키면 콘텐츠를 늘리려 조사부터 끝내야 하는 구조가 된다.
- **연도를 고정하지 않는다 — 배경은 "대항해시대쯤"이다(최상위 지침).** 특정 해에 맞추면
  그 해에 없던 도시·세력·선종을 계속 덜어내야 하고 수정 범위가 눈덩이처럼 커진다.
  **콘텐츠가 풍성한 쪽을 택한다 — 이왕이면 모두 나오게 한다.** 그래서 실제로는 공존하지 않은
  것이 한 화면에 있을 수 있다(기사단령 로도스 ↔ 기사단령 몰타). 그런 항목은 근거 JSON에
  `verdict: "gameplay"`로 표시해 **알고 그렇게 뒀다**는 것을 남긴다.
  개별 사실의 고증(무엇이 어디서 났나, 어느 항로가 위험했나)은 여전히 사료를 따른다.
- 웹 출력은 claude.ai Artifact 금지 — **로컬 HTML + 로컬 서버(`python serve.py`) + 브라우저**(사용자 지침).
- 에셋은 `js/sprites/`에 모아 **팩토리 함수만 노출**한다. 나중에 렌더링 이미지로 교체 가능하게(사용자 지침).
- 이미지 기준: **2D 픽셀 형태, 고급스러울 필요는 없지만 싸구려로 보이면 안 된다**(사용자 지침).

## 핵심 모델

- 논리 해상도 **400×225** 고정. 캔버스는 무대 전체, 게임 화면은 그 안에 정수배 중앙 배치(레터박스).
- **그림은 캔버스, 글자·버튼은 DOM 오버레이.** 픽셀 폰트 없이 한글 가독성을 얻는 방법.
- 모든 스프라이트는 `bake(key,…)` 캐시 — 매 프레임 호출해도 비용 0, 대신 수정 후 새로고침 필요.
- 씬: `port`(무역) ↔ `map`(항해) → `battle`(포격전→백병전), `port` → `shipyard`(선박·선원·무장·개장).
- 모듈 방향은 `data → state → world → scenes` **한 방향**이다. `world.js`(NPC)가 state를 쓰고, state는 world를 모른다(순환 참조 방지).
- **UI가 그림을 가리면 안 되는 화면은 패널을 `viewport()` 논리좌표에 얹는다** (조선소 씬이 본보기).

## 현재 상태

- 게임 루프 3파트(무역·항해·전투) + 조선소·술집 구현·브라우저 실동작 검증 완료.
- **공개 저장소**: `https://github.com/somanghao/tradeship` (public, main).
- **세 영역이 갈라져 있다** — 그림 / NPC / 지도. 경계와 절차는 `CONTRIBUTING.md`.
- 에셋은 전부 코드 생성이고 **PNG로 갈아 끼울 수 있다** — `bake` 키를 `assets/manifest.json`에 적으면 그것만 대체된다(키는 `preview.html`). 캐시는 **6MB LRU 상한**.
- **통합 대시보드** `/dashboard/` — **5탭**(오버뷰·경제·해적·항구·보수). 게임 모듈을 그대로 돌려 계측한다(재구현 아님). **오버뷰**가 계층 트리·동적 생성물·세이브 대상을 보여주고 그 정본(`dashboard/architecture.mjs`)은 `check-architecture.mjs`가 **실제 파일·실제 state와 대조**한다 — 구조 설명이 조용히 낡지 않는다. 파일 규약: `.mjs`=계측(DOM 없음) / `.js`=렌더. → `QUICKMAP-trade.md`
- **값은 `data.js`, 규칙은 `state.js`.** 콘텐츠 수치·도시 경제·**튜닝 상수 전부**(임금·보급·유지비·보험·급여 주기·시작 자금·조우 확률 환산)가 `js/data.js`에 모여 있고, 도시 좌표·항로·해류는 `js/map/geo.js`다. `state.js`는 그것을 그대로 re-export하므로 **기존 import 경로는 그대로 쓴다**. 밸런스를 만지려고 로직 파일을 열 일이 없다.
- **입항세는 두 겹이다** — 규모별 기본율(`TARIFF`)에 그 도시만의 오버라이드(`CITY_TARIFF`)를 얹는다. 지금 지정된 곳은 셋(알렉산드리아 8.5% · 이스탄불 7.0% · 제노바 4.5%)이고 나머지는 기본율로 굴러간다. 값을 적으면 `city-evidence.json`의 `tariff`에 근거도 적는다 — 검증기가 불일치·배선끊김을 실패시킨다. 항구 성질을 읽는 곳은 `baseTariff()`(부관 특전 제외).
- **데이터는 세 겹이다 — UI ▸ 수치 ▸ 근거.** 도시는 `map/geo.js` ▸ `data.js` ▸ `content/city-evidence.json`, 항로·관세도 같은 꼴이다. **수치를 고치면 근거도 같은 커밋에서** — `check-*`가 어긋나면 실패시킨다(*근거가 아직 없는 것*은 경고일 뿐).
- 특산품과 깃발은 15~16세기 사료에 맞춰져 있다. 밸런스나 연표만 보고 되돌리면 같은 오류가 재발한다.
- **부르사·이즈니크는 이스탄불에서만 들어가는 막다른 주머니**, **몰타**는 해협 병목의 **나포선 경매항**이다. 셋 다 의도적 예외다. → `wiki/city-goods-history.md`
- **시작은 물이 새는 낡은 바사 + 금화 200 + 선원 0명.** 배는 있는데 사람이 없어 **첫 행동이 매매가 아니라 술집행**이다. 항해할 때마다 선체가 삭아 갈아탈 압박이 걸린다.
- **선원은 술집에서 무리 단위로 모은다** — 자리마다 인원·기질(7종)·계약금·요구 일당이 다르고 **값이 두 갈래**다(계약금은 지금, 일당은 항해 내내). 싼 무리는 갑판에서 쓸모가 없다. 인원의 정본은 `state.crew`, `state.bands`는 누가 탔나의 기록 — `trimLoadout()`이 맞춘다. → `wiki/crew-tavern.md`
- **배는 도시 공업력이 정하고**(`industry ≥ SHIPS[].tier`), 상급선은 선행 선종을 몰아 봐야 열린다. 즉시 손에 넣는 길은 **중고선**뿐. 전투는 **탄종 선택**이 한 축이고 백병전으로 적선을 나포한다. → `QUICKMAP-combat.md`
- **부관은 오직 한 명, 에이미다** — **등용이 아니라 첫날부터 타고 있는 동행**이라 계약금도 해고도 없다. 항해술·전투는 손대지 않고 **오직 돈만** 만진다. 급여·성과급·능력은 **한 묶음**이라 함께 재측정한다. → `wiki/officer.md`
- **세계가 혼자 돈다** — NPC가 사고팔고 서로 습격하며 그 거래가 시세에 압력으로 남는다. 해적은 턴 만큼 부유해져 **현상금에 상한이 없다**. → `wiki/world-npc.md`
- **항로마다 위험이 다르다** — 근거는 **당대 해상보험 요율**(`map/geo.js: ROUTE_RISK`)이고 거기에 그 구간의 해적 수가 얹힌다. 조우 확률 10~28%(평균은 종전 18%와 같다 — 총량은 두고 갈랐다). 내해·육로는 **해적 대신 노상강도·통행세**가 난다(`INLAND_ODDS`).
- **경제는 "여러 항차"와 "대형 주문 한 건"이 나란하다.** 곡선은 `node tools/sim-trade.mjs` — **시드를 여러 판 평균한다**. → `wiki/economy-trade.md`
- **물가와 임금은 당대 사료 비율에 맞춰져 있다**. 대조 축은 둘뿐이다 — **곡물의 몇 배인가**와 **선원 연봉으로 무엇을 몇 개 사나**. ‘닢’은 실화폐가 아니라 절대액 환산은 안 한다.
- **급여는 발생주의다 — 날마다 쌓이고 30일마다 항구에서 치른다.** 물자·유지비는 즉시 나가고 급여만 쌓인다(`state.payroll`). 못 주면 **반란이 아니라 이탈**이다 — 사람이 조용히 사라지며 **값나가는 짐을 들고 간다**. 참을성(`CREW_TRAITS[].temper`)이 갈림길이라 싸게 태운 대가가 여기서 돌아온다. 정산 화면이 그 달 장부·선창·다음 밑천을 함께 보여준다. → `wiki/payroll.md`
- **항해비는 일곱 갈래로 갈라져 저마다 다른 성장 요인에 붙는다**(일당·보급·선체·무장·선단·적하보험·부관). 임금을 사료 쪽으로 내린 대신 **성장할수록만 무거워지는 쪽**으로 압박을 옮겼다.
- **값나가는 짐은 두 번 대가를 치른다** — 보험료가 오르고(`INSURANCE_RATE`) 해적 조우 확률도 오른다(`state.js: cargoLure`). 그래서 초반엔 곡물·소금을 안전한 이웃으로 나르고, 커져야 향신료·비단에 손을 댄다.
- **큰돈은 확률이 아니라 사건에서 나온다** — `state.shocks`가 시세를 한동안 올리거나(기근·봉쇄·나포) **내린다**(풍작·독점 붕괴). 후보는 매번 `CITIES`에서 만들어 **콘텐츠를 늘리면 사건도 저절로 는다**. 지도의 "뱃사람들의 소문"이 흔들리는 곳을 띄운다.
- **보험은 실제로 보상한다** — 폭풍이 심하면 짐을 던지고(공동해손) 잃은 값의 30%를 받는다(**낸 만큼만**). 화물 손실은 **20항차에 1건**으로 사료(보험료 중앙값 5%·전손률 4.7%)가 가리키는 빈도와 같다. 표·수치 → `wiki/economy-trade.md`

## 다음 후보 (사용자에게 선택 요청해 둔 상태)

- **★ 콘텐츠 확장 — 사용자가 명시한 방향.** 배·교역품·도시·해적의 *종류*를 늘린다. 지금 구조는 늘려도 막히지 않는다(사건 후보는 `CITIES`에서 매번 생성 · `check-*`는 미조사를 경고로만 잡는다). 어디부터일지는 미정.
- **관세를 사료 쪽으로** — 게임 3~6%(`TARIFF`) vs 사료 20%(알렉산드리아 impost). 두 원칙("어렵게 벌어야" + "근거에 충실")이 다 인상을 가리킨다. 다만 게임은 **매각에만** 물어 단순 비교가 안 되므로 **시뮬 곡선을 먼저** 낸다.
- **부동산·거점을 자산 sink로** — 항구별 창고·상관. 사료 앵커는 `content/asset-evidence.json`에 있고 대시보드 **항구** 탭이 배율로 환산해 보여준다. 게임 기능은 미구현.
- **술집 평판·부관 급여 유예** — 체불이 오래가도 어느 항구에서든 똑같이 태울 수 있다. 에이미는 떠날 수 없는 사람이라 급여만 밀리는데, "가난할 때 급여를 미루는 규칙"은 여전히 미구현이다.
- **그림 발주** — 항구 배경 16장은 의뢰서만 있고, **지도는 2차까지 반려**해 `manifest.json`이 비어 있다(붙이면 항구 점이 어긋난다). 다음 수는 코드 생성 지도(`SEA_SPANS`)를 실루엣 기준판으로 주고 재의뢰. → `QUICKMAP-art.md` §3
- **백병전 연출** — 포즈 전환뿐(`pixel.js: blitTinted` 준비됨·미사용).
- **세이브/로드** — 없음(새로고침 시 초기화). `Set` 두 개와 `fleet`·`shots`·`towing`·`officer`·`shocks`·`bands`·`hired`까지 함께 직렬화해야 한다.
- **바람/방향** — 항해에는 들어갔지만 **포격 페이즈에는 없다.** 선회가 거리 조절로만 추상화돼 있다.

보류: 사운드 없음 · 라틴세일 형태 뭉툭(게임에선 안 거슬려 방치) · 대포를 현측 포문에 물린 모습으로(포문 수 ≠ 대포 수라 규칙부터 손봐야 함).
