# 토픽: 조선소 — 선박 교체 · 갑판 배치 · 무장 · 개장

> `js/scenes/shipyard.js` + `state.js`의 선단/무장/배치/개장 규칙. 항구에서 `조선소로 간다`로 진입. (2026-08-13)

## 왜 전용 씬인가

원래는 항구 사이드패널의 모달이었다. 모달 폭(560px) 안에서는 176×128 선박 스프라이트가 작게밖에 안 들어가고,
뒤쪽 항구 화면까지 어둡게 덮여 **"배를 보지 못한 채 숫자만 보고 사는"** 화면이 됐다.
그래서 씬으로 뺐다 — 왼쪽 절반은 캔버스(배), 오른쪽 절반은 탭 패널.

## 레이아웃 — 패널을 논리좌표에 얹는다

항구 씬의 사이드패널은 **고정 px**(292px)라 창이 작아질수록 게임 화면을 많이 덮는다.
조선소 패널은 `viewport()`를 읽어 **논리좌표 x=206~388** 자리에 맞춰 인라인 스타일로 배치한다.

```js
const PANEL = { x: 206, y: 10, w: 182, h: VH - 20 };
const { offX, offY, scale } = viewport();
panelEl.style.left = `${offX + PANEL.x * scale}px`;      // 폭도 w * scale
```

- 배는 `SHIP_X = 12`, 수면 `SEA_Y = 170`. 스프라이트 폭 176이라 12~188 → 패널(206~)과 절대 겹치지 않는다.
- 씬의 `resize()`가 `layout()`을 부른다. main.js의 `fit()`이 `current?.resize?.()`로 호출해 준다.
- 이 방식이면 **창 크기와 무관하게** 배 전체가 보인다(scale 2인 좁은 창에서도 검증).

## 캔버스에 뭐가 그려지나

| 탭 | 배 | 그 외 |
|---|---|---|
| 선박 | 돛 편 상태. **줄을 누르면 그 배로 바뀐다(미리보기)** | 미리보기 중엔 갑판 병력을 안 그린다(내 배가 아니므로) |
| 선원 | 돛 접음 | 갑판에 `state.loadout` 병력이 서고 `sin`으로 미세하게 움직인다 |
| 무장 | 돛 접음 | 1.4초마다 포문을 하나씩 `firing`으로 번쩍이고, **실린 대포를 부두 바닥에 실물로 늘어놓는다**(`drawBattery`) |
| 개장 | 돛 편 상태 | 손보는 대상이 지금 탄 배임을 보이게 |

갑판 병력의 x는 **`HULLS[hull].x0` + `len×0.18`부터 `len×0.15` 간격**이다. 상수로 두면 낡은 바사(len 84)처럼
짧은 선체에서 병사가 뱃전 밖 허공에 선다 — 갑판선(y)을 `HULLS.deck`에서 가져오는 것과 같은 이유.

갑판선은 `shipY + HULLS[hull].deck - CHAR_FOOT` — 전투 씬 `deckOf()`와 같은 식이다. 선종마다 건현이 다르므로 상수로 쓰지 말 것.

## 선단 — 자동 매각이 없다

`state.fleet`: `shipKey → { at, hp, arms }`. 기함 포함 모든 보유 선박이 여기 들어간다.

| 함수 | 하는 일 |
|---|---|
| `purchaseShip(key)` | **구입만.** 기존 배는 그대로 둔다. 새 배는 현재 도시에 정박. **그 항구가 그 선종을 팔 때만**(`sellsShip`) |
| `boardShip(key)` | 갈아탄다. 같은 도시에 있어야 하고 화물이 들어가야 한다. 선실 초과분은 하선 |
| `sellShip(key)` | 정가의 55%(`SHIP_RESALE`). **타고 있는 배·다른 도시의 배는 못 판다** |
| `captureShip(key)` | 나포선을 선체 60%(`PRIZE_HULL`)로 편입. 같은 선종을 이미 가졌으면 해체 매각(`PRIZE_SCRAP` 0.30) |

### 국적 — 배는 아무 데서나 못 산다

`SHIPS[key].yards`가 그 선종을 내놓는 항구 목록이다. 목록 밖 조선소에서는 "타국 배"로 뜨고 어디서 파는지만 알려준다.

| 선종 | 국적 | 파는 곳 |
|---|---|---|
| 낡은 바사 | — | 없음(시작배, 매각만) |
| 카라벨 | 스페인 | 바르셀로나 · 팔레르모 · 나폴리 |
| 플류트 | 네덜란드 | 제노바 · 마르세유 |
| 브리간틴 | 영국 | 마르세유 · 팔레르모 · 로도스 |
| 캐랙 | 베네치아 | 베네치아 · 제노바 |
| 블랙월 프리깃 | 영국 | 제노바 · 바르셀로나 |
| 갈레온 | 스페인 | 바르셀로나 · 나폴리 |
| 인디아맨 | 영국·네덜란드 | 베네치아 · 이스탄불 |
| 슈퍼 프리깃 | 프랑스 | 마르세유 |

배를 사려면 그 나라 항구까지 가야 한다 — 항해 자체가 목표가 되게 하는 장치다. 수치는 `data.js: SHIPS`가 정본.

### 선단 유지비 · 최소 인원

- `fleetUpkeep()` = 기함을 뺀 정박 선박의 `upkeep` 합. `advanceDays()`가 일수만큼 걷는다(기함 몫은 선원 급여로 따로).
- `crewMin` 미만이면 `shorthanded()` — 돛을 다 못 펴 **속력 ×0.75**. 프리깃(45명)·슈퍼 프리깃(70명)은 사람을 많이 먹고,
  플류트는 화물 170에 14명이면 된다. "큰 배로 갈아탔더니 느려졌다"는 대개 인원 부족이다.

## 개장 — 배에 영구히 붙는 손질

`data.js: REFITS` · `state.refits`(기함) ↔ `fleet[key].refits`(정박선). **갈아타면 그 배에 해 둔 개장을 쓴다.**

| 개장 | 값 | 효과 | 구현 |
|---|---|---|---|
| 동판 선저 | 1,800 | 속력 +8% | `shipSpeed()` |
| 떡갈나무 장갑 | 2,400 | 선체 최대치 +25% | `maxHullOf()` → `recalcShip()` |
| 돛 증축 | 1,500 | 도주 +14%p · 속력 +5% | `fleeBonus()` |
| 내포격 골조 | 1,600 | 피격 시 선원 사상 −45% | `crewLossFactor()` |
| 4부 격실 | 2,800 | 격침 직전 **1회** 선체 22%로 버팀 | `battle.js: checkGunneryEnd` |
| 레이지 개조 | 3,600 | 속력 +15% · 포문 상한 −25% · 선체 −10% | `gunCap()` · `maxHullOf()` |

- **선체 최대치는 파생값이 아니라 상태값이다.** `state.maxHp`를 직접 들고 있으므로 개장·승선 후 `recalcShip()`으로 다시 계산해야 한다.
- 레이지 개조로 상한이 줄면 넘치는 대포를 **환불 없이 뜯어낸다**(`buyRefit`가 `dropped`로 알려준다). 뜯긴 것은 되사야 한다.

## 탄약고 — 특수탄

무장 탭 하단. `state.shots`에 재고를 쌓고 전투에서 한 발씩 소모한다(일반탄은 무한). 규칙과 효과는 → [battle-system.md](battle-system.md)

- `boardShip`은 먼저 `stowFlagship()`으로 지금 배의 선체/무장/정박지를 기록한 뒤 갈아탄다. 무장은 **배마다 따로** 붙어 다닌다.
- 기함의 정박지는 `map.js: arrive()`가 갱신한다(`state.fleet[shipKey].at = cityId`). 이 한 줄을 빼면 배가 출발 항구에 남는다.
- 카라벨 정가는 0이 아니라 **1,400닢**이다. 0이면 매각 버튼이 "매각 0"으로 떠서 팔 이유가 사라진다.

## 무장 — 대포 3종과 유효 구간

`data.js: CANNONS`. `state.arms = {light, medium, long}`, `state.guns`는 그 합계(`syncGuns`가 유지).

| | 피해 | 조준 | 잘 맞는 거리 | 값 |
|---|---|---|---|---|
| 경포 | ×0.95 | ×1.22 | 0~40 | 240 |
| 중포 | ×1.15 | ×1.00 | 0~70 | 420 |
| 장포 | ×1.38 | ×0.80 | 35~100 | 720 |

**핵심은 `near~far` 구간이다.** 이 밖으로 나간 만큼 조준이 무너진다(`state.js: zoneFactor`).

```
zone = max(0.4, 1 - (초과거리/50 + 미달거리/25))     // 가까운 쪽이 두 배 가파르다
armsAimAt(range) = Σ(문수 × aim × zone) / 총문수    // 포문 0이면 1.0
```

거리별 기대 피해(한 발, 바늘 균등분포 가정)로 검산하면 구간이 갈린다:

| | 10 | 30 | 50 | 70 | 90 |
|---|---|---|---|---|---|
| 경포 | **0.61** | **0.54** | 0.38 | 0.16 | 0.13 |
| 중포 | 0.61 | 0.54 | **0.47** | **0.40** | 0.20 |
| 장포 | 0.23 | 0.41 | 0.45 | 0.38 | **0.32** |

근접은 경포(게다가 값이 절반), 중거리는 중포, 원거리는 장포. 섞어 실으면 문수 가중 평균이라 구간을 메울 수 있다.

- 포문 상한 `gunCap()` = 선종 기본 포문 × 1.5. 철거하면 정가의 50% 환불.
- 전투 반영: `battle.js: fire()`의 base에 `armsFactor('dmg')`, `startAim()`의 판정대 폭에 `armsAimAt(B.range)`.
- **무장 탭은 산 대포가 눈에 보여야 한다.** 포문 깜빡임만으로는 경포를 싣든 장포를 싣든 그림이 같았다. `drawBattery()`가 편성 그대로를 부두(y=196~)에 늘어놓고, 패널 행에 마우스를 올리면 그 종류만 밝게 남는다(UI는 다시 그리지 않는다 — 떨림 방지).
  - 한 줄로 늘어놓으면 포신끼리 이어져 **파이프 한 개처럼** 보인다. 두 줄 지그재그(`BATTERY_ROW`) + 종류 사이 여백(`BATTERY_GAP`)이 필요하다.
  - 배치 폭은 **마지막 대포의 스프라이트 폭까지** 빼고 잡는다. 안 그러면 장포가 패널(x=206) 밑으로 들어간다. 갈레온 최대 36문까지 확인.
- **거리 배율(`range` 필드)로 판정대를 넓히던 옛 방식은 폐기.** 그 방식은 모든 대포를 "가까울수록 좋다"로 만들어 장포가 전 구간 1위, 경포가 전 구간 꼴찌가 됐다. 구간을 나눠야 선택이 생긴다.

## 갑판 배치 — 백병전 6칸

`state.loadout` 6칸. 0번은 선장 고정, 1~5번은 **선원 7명당 하나씩** 열린다(`openSlots()`).

- `setSlot(i, key)` — 기존 병종은 50%(`TROOP_REFUND`) 환불하고 차액만 낸다. 고용비는 `TROOPS[k].hire`.
- `playerTroops()`가 이 배열을 그대로 백병전에 넘긴다. 예전의 "선원 수로 자동 배정"은 없어졌다.
- **선원이 줄면 `trimLoadout()`을 불러야 한다.** 전투 종료(`finish()`)와 배 갈아타기에서 호출 중. 안 부르면 닫힌 슬롯의 병종이 유령으로 남는다.

## 함정

- **모달을 `document.querySelector('.modal')`로 닫지 말 것** — 숨어 있는 항해일지(`#logmodal`)가 먼저 잡힌다. `modal()`이 돌려주는 노드를 잡아 `.remove()`한다.
- 행 전체에 `onclick`을 걸었으므로 **행 안의 버튼 클릭을 걸러야** 한다(`if (ev.target.closest('button')) return`).
- 금화만 바꾸고 UI를 다시 그리지 않으면 버튼이 `disabled`인 채로 남는다. 상태를 건드리는 모든 경로는 `redraw()`로 끝낸다.
