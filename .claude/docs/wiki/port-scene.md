# 토픽: 항구 배경 생성

> `js/sprites/scene.js`의 `STYLES` / `building()` / `landmark()` / `portSprite(style, seed)` — 도시마다 다른 항구 풍경을 시드 기반으로 생성. (2026-08-08)

## 왜 프로시저럴인가

항구 도시가 13개다. 하나씩 그리면 13장을 손으로 그려야 하고, 도시를 추가할 때마다 작업이 늘어난다. 대신 **건축 양식 3종 × 도시 시드**로 조합해 생성한다.

`portSprite(city.style, city.seed)` → 같은 도시는 항상 같은 그림(시드 고정), 다른 도시는 다른 스카이라인.

## 세로 배치표 (필수 준수)

**이 순서를 어기면 뒤 요소가 앞 요소를 덮어 지운다.** 실제로 성벽을 바다보다 먼저 그렸다가 수면 아래로 잠겨 사라진 적이 있다.

```
y   0 ┌ 하늘 그라데이션 (skyGradient)
      │ 구름, 갈매기
   84 ├ 원경 구릉 2겹 (drawHills)
  112 ├ 시가지 뒷열   (groundY 112)
  122 ├ 시가지 중간열 (groundY 122)
  132 ├ 시가지 앞열   (groundY 132) + 랜드마크
  134 ├ 해안 성벽 (총안 130~, 몸체 134~152, 수문 132~152)
  150 ├ ★ HORIZON — 여기서부터 바다. 성벽 밑동이 물에 잠긴다
  186 ├ ★ QUAY_Y — 부두 상판 (석재 격자)
  195 │ 프롭 바닥선 pz = QUAY_Y+9 — 계선주·나무상자·통
  225 └
```

그리는 순서: `하늘 → 구름 → 구릉 → 시가지 3열 → 랜드마크 → 성벽 → drawSeaFront → drawQuay`

**주의:** `drawSeaFront`가 `HORIZON`부터 화면 끝까지 칠하므로, 물보다 앞에 있어야 할 것(부두, 부두 위 프롭)은 반드시 그 뒤에 그린다. 반대로 성벽처럼 "밑동이 잠겨야" 하는 것은 앞에 그린다.

부두 프롭을 `QUAY_Y` 기준 위쪽에 두면 **물 위에 떠 보인다.** 바닥선 `pz`를 쓸 것.

## 건축 양식 3종

| style | 도시 | 벽/지붕 | 랜드마크 | 특징 |
|---|---|---|---|---|
| `latin` | 베네치아·제노바·마르세유·바르셀로나·나폴리·팔레르모 | 미색 벽 + 테라코타 지붕 | `campanile` 종탑 | 박공지붕 |
| `hellenic` | 아테네·로도스·이스탄불 | 백벽 + 청색 지붕 | `dome` 돔 성당 | 밝고 채도 낮음 |
| `levant` | 튀니스·알제·베이루트·알렉산드리아 | 황토벽 | `minaret` 미나레트 + 돔 | 60% 확률로 **평지붕 + 난간** |

`STYLES[x]`가 `wall[3] / roof[3] / sky[3] / hill / tower / accent`를 들고 있다. 새 양식 추가는 이 표에 항목 하나.

## 시가지 생성

3열을 뒤→앞으로, 열마다 건물 폭·높이를 랜덤하게 이어붙인다.

```js
groundY = 112 + row*10        // 뒤로 갈수록 위
hMin = 14 + row*7             // 앞줄일수록 크다
hMax = 32 + row*13
w    = 8 + rand*16
```
건물 하나(`building()`)는 벽 → 좌우 그림자면 → 지붕(박공 or 평지붕) → 창문 격자.
창문은 22% 확률로 불이 켜지고(`P.goldM`), 30% 확률로 차양이 붙는다.

**대기원근:** 뒷열을 그린 직후 하늘색을 `globalAlpha` 0.30 / 0.14로 덮는다. 이게 없으면 3열이 전부 같은 선명도로 보여 평면적이다.

## 성벽

- 몸체 `y134~152` + 총안(`y130`, 10px 간격) + 화살구멍 + 하부 이끼
- **수문**: `x186~214`에 아치. 아치 아랫부분이 수면(150)에 닿아 배가 드나드는 느낌
- 방파제 기둥 2개(`x96`, `x288`) — 성벽과 부두 사이 깊이감

## 부두

- 석재 격자: 6px 행 간격, 홀짝 행마다 세로 이음을 6px 어긋나게(벽돌 쌓기)
- 계선주 5개(88px 간격) + 그 사이 **늘어진 밧줄**(sin 곡선)
- 화물: 나무상자(대각 보강재 X) / 통(철테 2줄), 접지 그림자 `#00000044`

## 항구 씬에서 얹는 것들

배경 스프라이트 위에 `scenes/port.js`가 실시간으로 그린다.

```js
// 정박한 우리 배 — 수면선을 항구 물높이(168)에 맞춘다
blit(ctx, shipSprite(hull, {furl:true}), 232, 168 - WATERLINE + bob, 1);

// 부두 NPC 3명 — 도시 시드로 고정 선발
blit(ctx, unitSprite(d.key,'idle'), d.x, 150, 1, d.flip);
```
배는 `furl:true`(돛 접음)로 정박 상태를 표현하고 `sin`으로 미세하게 흔든다.
