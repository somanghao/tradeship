# 토픽: 해상 전투

> `js/scenes/battle.js` + `js/data.js: ENEMIES/TROOPS/SHOTS` — 2단계 전투. 포격으로 몰아붙여 접현하고 백병전으로 나포한다. (2026-08-13)

## 설계 의도

**격침보다 나포가 이득**이어야 한다. 그래야 플레이어가 위험한 접현을 감수한다.

```
전리품 배율:  나포(백병전 승리) 1.00  vs  격침(포격으로 침몰) 0.45
화물 노획:    나포만 가능
```
포격만으로 이겨도 되지만 손해다. 이 비대칭이 전투의 축.

## 전체 흐름

```
        [포격전]  거리 100 ←→ 0
            │
            ├ 포격 (조준 미니게임)
            ├ 접근 / 이탈 (거리 조절)
            ├ 도주 시도
            └ 거리 ≤ 12 자동  또는  ≤ 26에서 수동 "백병전 돌입"
            ▼
        [백병전]  라운드제, 4자세
            │
            ├ 전멸시킴 → capture (나포)
            ├ 전멸당함 → lose
            └ 이탈(45%)
```
포격 중 적 HP 0 → `sink`(격침). 내 HP 또는 선원 0 → `lose`.

## 거리 (range)

`0`(접현) ~ `100`(원거리). 화면상 간격은 `gapOf(range) = 14 + range/100 × 68`.
백병전에서는 거리와 무관하게 `gap = 62`로 고정해 두 선체가 현측을 맞대게 한다.

| 거리 | 표시 | 효과 |
|---|---|---|
| >72 | 원거리 | 조준 판정대 좁음, 적 명중률 낮음 |
| 40~72 | 중거리 | |
| 14~40 | 근거리 | 판정대 넓음, 적 명중률 높음 |
| ≤12 | — | 자동 백병전 |

## 조준 미니게임

좌우로 왕복하는 바늘을 초록(명중)/노랑(치명타) 구간에서 멈춘다. `Space` 또는 발사 버튼.

```js
closeness = 1 - range/100
goodW = 0.20 + closeness × 0.24      // 판정대 폭 (거리가 가까울수록 넓다)
critW = 0.05 + closeness × 0.06
center = 0.30 + rand × 0.40          // 매번 위치가 바뀐다
speed  = 0.85 + rand×0.35 + range/260
```
**거리를 좁히는 것이 곧 명중률**이라는 구조. 안전한 원거리 저격은 어렵게 만들었다.

### 피해 계산

```js
base = (4 + guns × 1.15) × armsFactor('dmg') × SHOT.dmg
dmg  = round(base × (crit ? 2.1 : 1) × (0.85 + rand×0.30))
적 선원 사상 = round(dmg × (0.12 ~ 0.26) × SHOT.crew)
```
대포 6문 카라벨 = 명중 약 10, 치명타 약 22. 대포 증설(340닢/문)의 체감이 크도록 계수를 잡았다.

## 탄종 — 무엇을 재어 넣나

`data.js: SHOTS`. 조준 패널 안에서 고른다(바늘은 고르는 동안에도 움직인다). 일반탄은 무한, 나머지는 조선소에서 산 재고를 한 발씩 쓴다.
**재고가 비면 조용히 일반탄으로 물러난다**(`useShot`이 false를 돌려주면 `round`로 대체).

| 탄 | 값/발 | 피해 | 선원 | 돛 | 화재 | 쓰임 |
|---|---|---|---|---|---|---|
| 일반탄 | — | ×1.00 | ×1.0 | — | — | 선체를 부순다 |
| 포도탄 | 90 | ×0.45 | **×3.4** | — | — | 백병전 전에 머릿수를 깎는다 |
| 사슬탄 | 110 | ×0.35 | ×0.6 | **+22** | — | 적의 발을 묶는다 |
| 가열탄 | 170 | ×0.80 | ×1.0 | +8 | **3턴** | 지지고 빠진다 |

- **치명타면 돛 손상이 1.5배**. 화재는 매 턴 `maxHp×5% + 2`씩 태우고 턴수를 깎는다(`tickFire`).
- 적도 유탄으로 내 삭구를 끊는다(명중 시 22% 확률, +8~16).

### 돛 손상(`sailDmg`)의 효과

```js
rig = 1 - sailDmg/100
적 이동량 = 기본 × max(0.25, rig)
rig < 0.35 → 적은 접근·이탈을 포기하고 포격만 한다
도주 확률 += 적 sailDmg/100 × 0.30 − 내 sailDmg/100 × 0.25
```
"안전한 원거리"를 만드는 대신 **탄값**을 치르게 하는 축이다. 사슬탄 5발이면 적이 붙지 못한다.

### 도주 (개장 반영)

```js
포격전: 0.24 + range/100 × 0.52 + (shipSpeed()-1) × 0.25 + fleeBonus() + 돛 보정
백병전: 0.45 고정 (실패 시 강제로 '방진' 1라운드)
```

## 적 AI

```js
if (range > 70)                        approach   // 일단 붙는다
else if (선원비 > 1.25 && range > 18)  approach   // 백병 우세면 접현 노림
else if (HP < 25% && rand < 0.3)       withdraw
else                                   fire
명중률 = 0.34 + (1 - range/100) × 0.42
```
선원이 많은 적(코르세어·검은 깃발단)은 적극적으로 접현해 온다. 백병이 불리하면 플레이어가 거리를 유지해야 한다.

멀수록·빠를수록 잘 도망친다. 카라벨(1.35)은 원거리에서 약 90%.

## 백병전

### 병력 구성

```js
playerTroops()  // 선장 1 + round(crew/7)명, 최대 6
                // pool: sailor → swordsman → musketeer → pikeman → crossbow 순환
```
포격으로 선원을 잃으면 그만큼 약해진다:
`crewScale = max(0.35, 전투중선원 / 원래선원)` → 각 유닛 HP에 곱한다.

| 병종 | atk | def | hp | |
|---|---|---|---|---|
| 선장 | 20 | 12 | 40 | 항상 1명 |
| 총병 | 16 | 3 | 15 | 일제사격 특화, 물몸 |
| 창병 | 13 | 6 | 20 | |
| 석궁병 | 12 | 4 | 16 | 일제사격 특화 |
| 검병 | 11 | 9 | 24 | 탱커 |
| 선원 | 6 | 4 | 16 | |
| 코르세어 | 14 | 6 | 22 | 적 |
| 해적 | 10 | 4 | 18 | 적 |

### 자세 (라운드마다 선택)

| 자세 | 공격 | 방어 | 비고 |
|---|---|---|---|
| 돌격 | ×1.45 | ×0.65 | 빨리 끝내되 손실 큼 |
| 난전 | ×1.0 | ×1.0 | |
| 방진 | ×0.65 | ×1.55 | 버티기 |
| 일제사격 | 원거리 ×1.7 / 근접 ×0.6 | ×0.85 | 총병·석궁병이 많을 때 |

```js
피해 = max(1, round(atk × 자세배율 × (0.8~1.25) - 대상def × 0.42 × 방어배율))
```
양측이 **동시에** 공격한다(적은 그 라운드에 죽은 유닛 제외). 라운드 결과는 선원 수에도 반영: `crew -= round(누적피해/7)`.

### 화면 배치

```js
deckY = SEA_Y - WATERLINE + bob + HULLS[hull].deck - CHAR_FOOT
```
선종마다 건현이 달라 **갑판선을 `HULLS`에서 직접 가져와야** 한다. 상수로 박았다가 병사들이 돛대 높이에 떠 있던 적이 있다. → [pixel-pipeline.md](pixel-pipeline.md)의 기준선 표

아군은 `yourX+92`부터 오른쪽으로, 적은 `foeX+60`부터 왼쪽으로 16px 간격. 죽은 유닛은 제외하고 다시 정렬한다.

**등장 확률은 플레이어 자산에 연동**된다 (`pickEnemy`):

```js
if (지금 탄 배가 leak 있음)  → 1티어 90% / 2티어 10%   // 볼품없는 배는 큰 놈이 상대해 주지 않는다
wealth = gold + 화물수 × 60
wealth > 30000 → [0.05, 0.10, 0.25, 0.35, 0.25]
wealth > 14000 → [0.10, 0.25, 0.40, 0.20, 0.05]
wealth >  6000 → [0.30, 0.42, 0.24, 0.04, 0.00]
wealth >  2000 → [0.62, 0.32, 0.06, 0.00, 0.00]
else           → [0.88, 0.12, 0.00, 0.00, 0.00]
```
낡은 바사로 시작하는 초반이 필패가 되지 않게 **배 자체로 한 번 더 거른다**.

## 나포 편입 (prize)

백병전으로 이기면 `ENEMIES[].prize` 선종을 선체 60%(`PRIZE_HULL`)로 선단에 넣을 수 있다 — 아르고노트가 센츄리온이 된 그 방식.

- 결과 모달에서 **예인 / 버려두고 떠남**을 고른다. 예인하면 `state.towing`에 걸리고, `map.js: arrive()`가 **다음 입항지 부두**에 매어 둔다.
- 같은 선종을 이미 가지고 있으면 끌고 갈 인원이 없어 **해체 매각**(정가 30%).
- 코르세어(갤리)는 `prize: null` — 부술 수만 있다.

## 패배 처리

즉시 게임오버가 아니다. 금화 50% + 화물 전량을 빼앗기고 HP 25%, 선원 50%로 항구에 예인된다. 재기 가능.
**4부 격실**을 개장했으면 선체가 0이 되기 직전 한 번, HP 22%로 버티고 불도 꺼진다(전투당 1회, `B.saved`).

## 이펙트

`addFx(kind, x, y, life)` → `fx[]`에 쌓고 `drawFx`가 `t/life`로 프레임을 고른다.
`blast`(4프레임) / `smoke`(상승+페이드) / `splash`(빗나감) / `ball`(포물선 비행).
화면 흔들림은 `B.shake`(피격 1.1, 발사 0.5)가 초당 3.4로 감쇠.
