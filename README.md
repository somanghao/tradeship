# 지중해 교역기 (tradeship)

대항해시대 2 풍의 지중해 무역·전투 캐주얼 게임. 순수 ES 모듈 + Canvas, **빌드 과정이 없다**.
모든 픽셀 에셋은 코드로 그린다 — 이미지 파일이 하나도 없다.

## 실행

```bash
python serve.py            # 8891 포트
python serve.py 9000       # 포트 지정
```

브라우저로 <http://localhost:8891/index.html> 을 연다.
에셋 미리보기는 <http://localhost:8891/preview.html>.

> `python -m http.server`를 쓰면 안 된다. `Cache-Control`을 보내지 않아 낡은 `.js`가
> 섞이고, import가 링크 단계에서 실패해 화면이 통째로 검게 남는다. `serve.py`는
> `no-store`를 강제한다.

## 게임

물이 새는 낡은 바사 한 척과 금화 900닢으로 베네치아 부두에서 시작한다.
항해할 때마다 선체가 삭기 때문에 제대로 된 배로 갈아탈 압박이 계속 걸린다.

- **무역** — 13개 항구를 잇는 항로망. 산지에서 싸게 사 수요지에 판다. 시장에는 깊이가 있어
  한 번에 쓸어 담을수록 단가가 불리해지고, 날이 지나면 회복한다. 입항세는 파는 쪽에만 붙는다.
- **대형 주문** — 항구마다 걸린 큰 계약. 화물은 직접 조달해야 하고 기한도 있지만 시세보다 후하다.
  선금만 받고 파기하면 손해가 나도록 위약금이 설계돼 있다.
- **항해** — 계절풍과 해류가 소요 일수를 가른다. 배마다 가로돛 비율이 달라 순풍·역풍 성능이 갈린다.
- **전투** — 포격전 → 백병전. 탄종 선택이 한 축이다(포도탄=선원, 사슬탄=돛, 가열탄=화재).
  백병전으로 이기면 적선을 선단에 편입한다.
- **조선소** — 선단·갑판 배치·무장·개장 4개 탭. 배는 **국적별 조선소에서만** 판다.
  대포마다 잘 맞는 거리 구간이 달라 근접/중거리/원거리 1위가 갈린다.
- **살아 있는 세계** — 상인·해적 NPC가 실제로 사고팔고 서로 습격한다. 그 거래는 플레이어가
  보는 시세에 그대로 압력으로 남는다. 늦게 가면 이미 쓸어간 뒤다.

## 구조

```
index.html          진입점 (캔버스 + DOM 오버레이)
preview.html        코드 생성 에셋 미리보기
serve.py            no-store 개발 서버
js/
  data.js           도시·교역품·선박·적 정의 (수치의 정본)
  state.js          게임 상태와 규칙 (렌더링과 무관한 순수 로직)
  world.js          저 혼자 도는 상인·해적 NPC
  main.js           씬 전환과 루프
  pixel.js  ui.js   픽셀 유틸 / DOM 오버레이
  scenes/           port · map · battle · shipyard
  sprites/          char · ship · scene · icons  (전부 코드 생성)
tools/
  sim-trade.mjs     무역 곡선 시뮬레이터 — "다음 배까지 몇 항차인가"
  test-rules.mjs    규칙 회귀 테스트
  test-world.mjs    NPC 세계 테스트
.claude/docs/       설계 문서 · 도메인별 퀵맵 · 변경 이력
```

설계 원칙 몇 가지:

- 논리 해상도 **400×225** 고정. 캔버스 안에 정수배로 중앙 배치(레터박스).
- **그림은 캔버스, 글자·버튼은 DOM 오버레이.** 픽셀 폰트 없이 한글 가독성을 얻는 방법.
- 모든 스프라이트는 `bake(key, …)`로 캐시한다 — 매 프레임 호출해도 비용이 없다.
- 모듈 방향은 `data → state → world → scenes` 한 방향. `world.js`가 state를 쓰고,
  state는 world를 모른다(순환 참조 방지).

## 검증

```bash
node tools/test-rules.mjs    # 규칙 회귀
node tools/test-world.mjs    # NPC 세계
node tools/sim-trade.mjs     # 자산 곡선 — 수치를 고치면 이걸 함께 본다
```

밸런스는 눈으로 판단하지 않는다. 수치를 바꾸면 `sim-trade`의 곡선을 함께 확인한다.
